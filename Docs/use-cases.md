# EngiSense AI — User Personas & Use Cases

## 1. User Personas

### Persona 1 — Engineering Student

An engineering student who works with laboratory measurements, project datasets, technical papers, datasheets, and engineering documentation.

#### Goals

- Analyze engineering datasets
- Understand technical documents
- Generate useful visualizations
- Ask technical questions using natural language
- Learn from engineering data

#### Typical Workflow

```text
Upload Dataset
      ↓
Analyze Data
      ↓
Generate Visualizations
      ↓
Upload Technical Document
      ↓
Ask AI Questions
      ↓
Understand Results
