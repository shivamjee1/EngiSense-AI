# EngiSense AI

AI-Powered Engineering Intelligence Platform.

## Overview

EngiSense AI is a full-stack engineering intelligence platform that combines:

- Engineering dataset analysis
- Data visualization
- Technical document intelligence
- Retrieval-Augmented Generation (RAG)
- Generative AI
- Full-stack web development
- Engineering-focused analytics
